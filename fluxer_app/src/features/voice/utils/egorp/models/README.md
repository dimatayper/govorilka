# Egorp inference model

`dpdfnet2_48khz_hr.onnx` is the unmodified Ceva-IP DPDFNet2 48 kHz high-resolution model.

- Project: https://github.com/ceva-ip/DPDFNet
- Model: https://huggingface.co/Ceva-IP/DPDFNet/resolve/main/onnx/dpdfnet2_48khz_hr.onnx
- License: Apache-2.0, included in `LICENSE-DPDFNet`.
- SHA-256: `7f0575a5cec0ba4ffd8f8bd657e06d007e4ccdd955d76faab922b9d3291dc14b`

Bundled as a content-hashed application asset; runtime verifies this checksum before inference.
The normalizer initialization values in `../DpdfModelConfig.ts` come from this model's metadata.
